# Upgrade to Umbraco 19

From Umbraco CMS `[18.0.0, 18.999.999)` / Umbraco Commerce `[18.0.0, 18.999.999)` to CMS `19.0.0-beta1` (tag `release-19.0.0-beta1`) / Commerce `19.0.0-beta.1`.
Branch `topic/19.x/cms-19-upgrade` → PR into `release/19.0.0`, cut from `main` (`59350b3`).

**Targets CMS release:** `release-19.0.0-beta1`. The package's own version is `19.0.0-beta.1`.

The CMS breaking-change inventory for 19.0.0-beta1 was done for Commerce Core (Core repo, `docs/upgrades/v19.md`, 53 `@umbraco-cms/backoffice` import paths, manifests, elements, contexts and the `category/breaking` PRs). This file lists only what hits Product Feeds, checked against that list, a v18 and a v19 build (CS0618), and `@typescript-eslint/no-deprecated` on v18 and v19 typings.

## Tasks

Each task ends in a green build.

- [ ] 1. Bump to .NET 11, the pinned SDK, Umbraco.Cms 19.0.0-beta1 and Umbraco.Commerce 19.0.0-beta.1. Drop the duplicate `TargetFramework` from `Directory.Packages.props` and the unused `Umbraco.Cms.Web.Website`/`Umbraco.Cms.Web.BackOffice` versions.
- [ ] 2. Replace the Examine product lookup with the published content tree under the product root (descendants of the chosen document types; published, routable, not protected, as `ExternalIndex` gave). Keep the `IExamineManager` constructor as `[Obsolete]` (v21). Unit tests.
- [ ] 3. Frontend: `@umbraco-cms/backoffice` 19.0.0-beta1, `@umbraco-commerce/backoffice` 19.0.0-beta.1, `@hey-api/openapi-ts` ^0.99 with the fetch client, regenerate, `authContext.configureClient`, drop axios. Validate `umbraco-package.json` against the 19 schema.
- [ ] 4. Compatibility markers: version `19.0.0-beta.1` (`version.json`, frontend `package.json`); package validation off with baseline `19.0.0`.

## Decisions

- Product lookup uses the content tree, not Umbraco Search (maintainer, 30-10-2026): a feed lists every product under one root, so nothing needs a search index; only use search if the tree would lose functionality.

## Breaking changes for consumers

- Requires Umbraco 19 / Umbraco Commerce 19 (.NET 11).
- `ProductQueryService`: new constructor without `IExamineManager`; the old one is `[Obsolete]` (removal in v21.0.0).
